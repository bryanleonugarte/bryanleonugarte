## 🚀 Featured Projects

### 🔧 [Well Pump Cycle Analyzer](https://github.com/bryanleonugarte/well-pump-cycle-analyzer)
Automated Python pipeline that processes sensor data from 20+ wells, detects 
ON/OFF pump cycles and calculates water volume (m³) per cycle — replacing several 
hours of manual work every two weeks.  
**Tech:** Python · Pandas  
**Result:** biweekly process reduced from hours to minutes

### 🗺️ [Soil Texture Interpolation Map](https://github.com/bryanleonugarte/soil-texture-interpolation)
IDW spatial interpolation of soil sand content (%) using QGIS, generating 
management zone maps to correlate soil texture with uneven crop growth and 
inform precision irrigation decisions.  
**Tech:** QGIS · IDW interpolation  
**Method:** Bouyoucos hydrometer · USDA soil texture triangle
